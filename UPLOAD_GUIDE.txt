노벨상 키우기 — CSV 시나리오 통합판

업로드
1. ZIP 압축을 풉니다. ZIP 자체를 GitHub에 올리면 게임이 업데이트되지 않습니다.
2. 아래 세 파일을 기존 저장소의 nobel.html과 같은 최상위 폴더에 함께 올립니다.
   nobel.html
   scenario-data.js
   scenario-engine.js
3. 기존 에셋 폴더는 그대로 사용합니다. index.html은 기존의 nobel.html 이동 파일을 사용합니다.
4. 브라우저에서 새로고침합니다. Windows Chrome에서는 Ctrl+Shift+R로 새 파일을 불러올 수 있습니다.
5. test.js, test-modal.js, test-scenarios.js는 개발 점검용이며 함께 업로드해도 됩니다.

포함된 콘텐츠
- 기본 상황 500개, 상황별 변형 10개: 총 5,000개.
- 기본 선택지 15,000개, 후속 기회/보완 카드 50개.
- 장기 연쇄 12개의 마디·이전 기록과 분야별 제목·발단을 포함합니다.
- 사용자 CSV 원문 ID와 10개 원본 CSV의 SHA-256 해시를 scenario-data.js에 보존했습니다.
- 데이터 파일의 크기는 약 6.9MB입니다. CSV의 반복된 문구·조건·효과 객체는 공유 테이블로 묶었습니다.

게임에서 등장하는 방식
- 학기 중 두 번 선택 기회를 배치하고, 해당 시점의 실제 경력·학기·나이·활동·이력으로 적격 상황을 추첨합니다.
- 조건을 만족하는 사건이나 고를 수 있는 선택지가 없으면 일반 학기 기록이 이어집니다.
- 기본 상황은 한 인생에서 한 번만 등장합니다. 같은 상황의 다른 V번호도 반복하지 않습니다.
- 기한이 된 후속 보완을 우선합니다. 최근에 쓴 변형의 가중치를 낮추고, 아직 안 쓴 변형을 우대합니다.
- 선택 시점에 확률과 난수를 저장하므로 새로고침으로 결과를 다시 뽑지 않습니다.
- 기존 저장을 이어할 수 있습니다. 과거에 없던 새 선택 이력이나 관계는 만들어 넣지 않습니다.
- 팝업 너비는 앞서 조정한 최대 398px를 유지합니다. 긴 본문과 선택지는 팝업 안에서 스크롤됩니다.

시간·자원·보상
- 매 학기 사건에 쓸 추가 재량 시간 4, 기관 지원 이용권 2를 배정합니다. 실제 제도가 아닌 게임용 수치입니다.
- 시간·기관 지원·실제 개인 지출이 부족하면 해당 선택을 잠급니다. 무료 선택은 잔고가 음수여도 가능합니다.
- 준비금은 소비로 차감하지 않고 별도로 묶으며, 선택에 쓸 수 있는 현금에서만 제외합니다.
- 회복 선택에 일정 취소가 필요하면 실제로 남은 추가 일정 하나를 취소하고 해당 일정에 배분된 능력치 성장분을 되돌립니다.
- 요청, 실제 도움, 검증, 보완, 기여 인정 등을 서로 다른 이력으로 남깁니다.
- 이력은 주제와 당사자·연구 계보가 같을 때만 누적합니다. 다른 사람의 이력·미래 기록·같은 학기 중복으로 조건을 채우지 않습니다.
- 확정 선택은 본인의 행동만 확정합니다. 기존 학위·진학·논문 게재·교수 임용·승진 심사는 그대로 진행합니다.
- 추가 사건은 논문, 수상, 상금 입금, 공식 승인이나 상대의 동의를 임의로 만들어 주지 않습니다.
- 후속 기회는 연락을 확인한 뒤 선택합니다. 실제 의무의 보완은 남은 항목이 끝날 때까지 다음 학기로 이어집니다.
- 엔딩에 남은 보완 기록, 기한이 지난 기회와 내려놓은 기회를 표시합니다.

원작에 없는 상태에 대한 처리
- CSV 안내에서 확장 항목으로 분리한 정교수 지속 플레이는 기본적으로 꺼져 있습니다. 원작은 정교수 승진 시 엔딩입니다.
- 자녀, 동거, 학생·지원자·졸업생 명부, 학자금 대출, 실제 자료 요청 등 원작에 확인 기록이 없는 상태는 없는 것으로 유지합니다.
- 따라서 해당 상태가 필요한 일부 상황·변형은 현재 플레이에서 등장하지 않습니다. 5,000개 모두의 조건을 무시하고 무작위로 섞는 방식은 사용하지 않았습니다.
- 전문연 선발과 실제 복무 완료는 구분합니다. 자격·완료 확인이 없는 상태에서 완료 사건을 만들지 않습니다.
- 분야·학교 이름만으로 개인 능력치, 공정성, 동의 여부를 보정하지 않습니다.

점검
node test-scenarios.js
node test-modal.js
node test.js

test-scenarios.js: 콘텐츠 참조, 조건·범위 이력·순서·비용·1회 노출·저장 난수·후속 확인·부분 보완 검사.
test-modal.js: DOM 하니스에서 실제 화면 생성 코드와 이벤트 처리 검사. 실제 브라우저의 렌더링 검사는 아닙니다.
test.js: 기존 3,000회 자동 플레이와 관계·진학·박사 이후 경력 검사.

이 환경에서는 브라우저 실행이 차단되어 실제 브라우저에서 새 콘텐츠의 화면·성능·레이아웃은 확인하지 못했습니다.
