# 노벨상 키우기 · 로컬 수정판 v0.2

원본 `myunlee133-beep/nobel-kiugi`의 `c257f55`를 바탕으로 2026-11-15에 수정했습니다. 피드백 반영 내용은 `codex/feedback-v0.2` 브랜치에서 관리합니다.

## 실행

Windows에서 **`게임 실행.cmd`를 더블클릭**하면 기본 브라우저로 열립니다. Python 3가 필요하며 추가 설치 패키지는 없습니다.

터미널에서 실행하려면:

```powershell
python run-local.py
```

주소는 `http://127.0.0.1:8766/nobel.html`이며, 종료는 실행 창에서 `Ctrl+C`입니다. 서버 없이 `nobel.html`을 브라우저로 직접 열어도 플레이할 수 있지만, 저장 기능은 위 실행 방식을 권장합니다.

## 달라진 점

- 수능 성적을 확인한 뒤 대학을 지원합니다. 고교·전공 보정을 먼저 적용하고 실제 합격 확률을 표시합니다.
- 과외는 대학별 초기 수요, 수능 성적, 강의력, 지도 경력에 따라 모집 확률과 수입이 달라집니다. 모집 실패 시 수입은 없습니다.
- 등록금·장학금·집안 지원·생활비·월세·이자·사건별 거래와 투자 수익률을 가계부에서 확인합니다.
- 평점·수상·발표·논문·연구 인연이 대학원 심사에 반영됩니다. 불합격 이후의 선택도 생겼습니다.
- 1·2·4배속, 일상 빠르게 넘기기, 조용한 학기 자동 결산, 프롤로그 즉시 표시를 지원합니다.
- 학업·경제 활동은 체력을 씁니다. 휴식, 진학 준비, 자금 부족, 휴학·근로가 다음 학기에 영향을 줍니다.
- 조건부 활동과 인물 사건, 발견의 연속 사건, 기록을 반영한 ‘30년 뒤’ 에필로그를 추가했습니다.
- 재추첨 방지, 게임 안 확인 창, 자동 저장과 백업 3개, 인물 이름·조사·용어를 정리했습니다.

전체 반영 범위와 남은 제안은 **[수정 내역](수정%20내역.md)**에 정리했습니다. 원본 기획서는 비교를 위해 보존했습니다.

## 저장

현재 인생 1개와 백업 3개를 브라우저에 보관합니다. ‘설정 → 저장한 인생’에서 백업하고 불러올 수 있습니다. 같은 인생의 이전 시점을 불러올 때에도 현재 시점을 백업합니다. 저장 위치는 브라우저와 접속 주소에 따라 달라집니다.

수정판은 `nobel.v2.*` 저장 키를 써서 원본의 `nobel.life`를 덮어쓰지 않습니다. 원본 인생의 자동 변환은 제공하지 않습니다.

## 개발·검증

```powershell
node test.js
```

실제 브라우저와 같은 `data.js`·`engine.js`를 이용한 규칙 검증 및 1,000회 자동 플레이를 실행합니다. `reports/`에 검증 결과와 모바일 화면을 남겼습니다.

게임의 학교명·가격·소득·합격 확률은 가상 설정과 밸런스 초안입니다. 실제 대학별 통계나 현재 제도의 정확한 수치를 재현한 모델은 아닙니다. 도트 글꼴은 원본과 동일하게 CDN에서 불러오며, 연결이 없으면 기기 기본 글꼴로 동작합니다.
